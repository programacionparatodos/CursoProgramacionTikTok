## ⏰ Horarios Tentativos (Lunes a Viernes)
Los directos se realizan en tres turnos flexibles a lo largo del día.

### 🕒 Turnos Base (Hora de Bolivia)
* 🌅 **Turno Mañana:** A partir de las **09:00 o 09:30** en adelante.
* 🌆 **Turno Tarde:** A partir de las **15:00 o 15:30** en adelante.
* 🌃 **Turno Noche:** A partir de las **21:00 o 22:00** en adelante.
